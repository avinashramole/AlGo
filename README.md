# T2S Algo Terminal

Web UI for the T2S algorithmic trading desk: live index tape, candlestick chart, AI signals, option chain, algo toggles, and positions.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```

Demo data is mocked for NIFTY, BANKNIFTY, FINNIFTY, SENSEX, and INDIA VIX. No live broker connection is required.
